HTML 批量对比工具

HTML Diff Compare

批量对比两个文件夹中 HTML 文件的差异，自动忽略 class/style 等标签属性，只关注用户可见的文本和图片变化。支持 index.json 文件映射和命令行调用。

批量对比 智能过滤属性 差异高亮 导出报告 命令行支持

界面词校验工具

Term Checker

从 PDF 手册中智能提取界面词（被引号包裹的 UI 文本），通过上下文关键词过滤代码噪音，自动对照中英术语表标记未登记的界面词，并支持 PDF 高亮定位。

智能提取 术语核对 PDF 定位 忽略标记 导出结果
下载 EXE

界面词定位工具

Term Locator

以中文手册界面截图为切入点，基于 PaddleOCR 批量识别截图文字并建立索引；输入关键词即可在全部截图中红框定位界面词位置，词性语境一眼可辨，索引可保存复用与团队共享。

OCR 识别 界面词定位 红框高亮 索引缓存 索引共享

XML 文件排序工具

SortTool / SortUndo

将翻译系统导出的 XML 文件按手册目录架构一键排序：文件夹拖到图标上即自动解析 XLF 添加序号前缀，配套 SortUndo 翻译后一键还原原始文件名。

拖拽排序 XLF 智能匹配 多级模糊匹配 一键还原 命令行支持

关于我

技术栈与背景

我是一名专注于效率工具开发的工程师，擅长用 Python 将重复性人工操作自动化。熟悉桌面应用开发（PyQt5/Tkinter）、OCR 应用、Windows 端软件打包分发。

我的工具均来自真实工作场景：从文档对比、术语校验到 OCR 定位，每一款都经过实际项目的反复验证和迭代。
